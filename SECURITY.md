# Security Policy

## Supported Versions

The following table lists the security support status for versions of `tree-sitter.zig`:

| Version | Supported | Recommended Zig Version |
| :--- | :--- | :--- |
| `0.0.2` | :white_check_mark: | Zig 0.17.0+ |
| `< 0.0.2` | :x: | Zig 0.16.0 |

## Reporting a Vulnerability

If you discover a security vulnerability in `tree-sitter.zig`, please report it responsibly:

- **Email**: Send vulnerability reports directly to [contact@muhammadfiaz.com](mailto:contact@muhammadfiaz.com).
- **Public Issues**: Please **do not** report security vulnerabilities through public GitHub issues or discussions.

### What to Include in Your Report

To help us investigate and resolve the issue quickly, please include:

1. A clear description of the vulnerability.
2. Steps or a minimal reproducer to trigger the behavior.
3. The affected environment (OS, architecture, Zig version).
4. Any potential impact or attack vectors.

### Response Timeline

- **Acknowledgment**: You will receive an initial response acknowledging your report within **48 hours**.
- **Assessment**: We will investigate and provide an assessment and timeline for a fix within **7 days**.
- **Fix & Disclosure**: Once a patch is developed and verified, we will coordinate a release and publish a security advisory.
