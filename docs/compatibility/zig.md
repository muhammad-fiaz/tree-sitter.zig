# Zig

tree-sitter.zig targets **Zig 0.17.0+** (`minimum_zig_version = "0.17.0"`, verified against the local SDK standard library — not older-version idioms). All APIs build directly on the Zig 0.17.0 standard library (`std.Io`, explicit allocators, monotonic clocks).

Related: [Zig 0.17 Notes](/development/zig-0.17), [Feature Matrix](/compatibility/feature-matrix).
